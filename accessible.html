I ran a scan and got an axe-core error on this page. Why?

You probably found the "All page content should be contained by landmarks" (region) flag on the disclaimer line right below the nav. It's real: that line genuinely sits outside every landmark on this page. But look up its details and you'll find it tagged best-practice, not a numbered WCAG success criterion. axe-core ships two kinds of rules side by side, in the same report, with the same red styling: rules that map to a WCAG failure, and rules that check organizational best practices with no direct WCAG mapping. This page passes every WCAG-mapped rule. That one best-practice flag is real, and worth knowing about, but it's not the same thing as an accessibility barrier for an actual person: the text is static, always visible, and equally readable to everyone regardless of which landmark contains it.

The lesson generalizes past this one rule: a scanner result is a starting point, not a verdict. Some flags need a fix. Some need five seconds of judgment to confirm they're fine as-is. Knowing which is which is the actual skill, and a scan can't do that part for you.
