Vesper Visible

The same landing page, built twice. One version treats accessibility as an afterthought — the other builds it in from the start. Same layout, same content, same look at a glance. Only the markup underneath is different, and that's exactly what changes everything for someone using a keyboard, a screen reader, or a Vesper Toolkit bookmarklet.

Inaccessible version

Div-buttons, missing labels, broken heading order, a positive tabindex trap, low-contrast text, a fixed-width table. Nine deliberate barriers, one per common issue.

Accessible version

The exact same page, corrected point by point. Real buttons, real labels, a sound heading order, sufficient contrast, a table that reflows.

Open the accessible version

How to use this

  • Put your mouse away and tab through both pages with the keyboard alone. Notice where the focus goes missing, or where it jumps somewhere unexpected.
  • Turn on a screen reader (VoiceOver, NVDA, TalkBack) and listen to both. This is the comparison point that's usually missing: the same content, sounding completely different depending on the markup.
  • Run any 🦇 Vesper Toolkit bookmarklet on both — Headings, Tab Order, ARIA Reader, Contrast, Link/Image/Label Scan, or a full AC Scan. Compare what each one reports.
  • Then open "view source" (or your browser's dev tools). Every deliberate issue has a comment right above it explaining what's wrong and why — and the accessible version has the matching comment explaining the fix.
